# 🛡️ InternShield AI

An AI-powered web application that helps students identify fake internship offers and scam recruitment messages.

## ✨ Features

- 🔍 Analyze internship offers
- 🤖 AI-powered scam detection (coming soon)
- ⚠️ Risk score and warning indicators
- 📱 Fully responsive UI
- 🎨 Modern Tailwind CSS design

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Git & GitHub

## 🚀 Getting Started

```bash
npm install
npm run dev
```
